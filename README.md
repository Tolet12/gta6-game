NEON PALMS is an original open-world crime game set in the sun-soaked coastal city of Palmera Bay, built with Three.js and plain ES modules. Play a courier who takes hotter and hotter jobs — checkpoint runs, a hot package, a full-heat getaway — while traffic, pedestrians and a scaling police wanted system fill the streets, then keep the city as your free-roam sandbox.

## Run it

```sh
node serve.ts
# serves the game at http://localhost:8080
```
